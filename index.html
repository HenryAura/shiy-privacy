「识词」（以下简称"本应用"）是一款面向大学英语四六级备考人群的词汇检测与记忆应用。我们深知个人信息对您的重要性，并在此承诺：本应用不注册、不登录、不追踪，您的学习数据不出您的设备。

请在使用本应用前仔细阅读本政策。您下载、安装或使用本应用，即表示您已理解并同意本政策的内容。

一、我们收集的信息

本应用不收集以下信息：您的姓名、手机号、邮箱、身份证件等任何身份信息；您的位置信息；您的通讯录、相册、剪贴板内容；将您的设备识别符用于广告或用户画像；任何广告标识符。

本应用也不接入任何第三方统计、分析或广告 SDK，没有任何数据被上报至开发者或第三方的服务器。

1.1 存储在本机的学习数据

您在使用过程中产生的以下数据，仅保存在您设备本地的应用数据库中，不经过任何网络传输至开发者：

  • 学习记录：答题历史（题目、作答结果、时间）、每轮练习明细；
  • 学习进度：每个单词的掌握状态、错词本、间隔复习计划；
  • 学习偏好设置：词库级别、练习方式、出题范围、每日目标、外观主题等；
  • 词典使用数据：搜索历史、本地快照备份；
  • 考试日期与提醒开关状态。

上述数据通过每轮练习后在本机自动生成的快照留存，可随时通过卸载应用或清除应用数据彻底删除。

1.2 词库数据

四六级词库、例句、构词数据全部随应用安装包内置，加载与查询均在本地完成，不联网获取词库内容。

二、权限使用说明

本应用遵循"最小必要"原则申请系统权限，全部权限用途如下：

权限用途触发时机
ohos.permission.INTERNET（网络访问） 仅当您主动配置 WebDAV 服务器并使用"备份/恢复"功能时，用于连接您自己指定的 WebDAV 存储服务上传或下载您的学习数据备份。除该场景外，应用不发起任何网络请求 用户主动触发
ohos.permission.PUBLISH_AGENT_REMINDER（本地提醒） 当您开启"考试提醒"功能后，用于在本地定时发布学习提醒通知（如"距考试还有 N 天"） 您在设置中开启提醒时

2.1 通知授权

当您在"设置 > 考试提醒"中手动开启提醒开关时，系统会弹出通知授权询问。您可以拒绝，拒绝后仅提醒功能不可用并自动回弹开关，应用其余功能完全不受影响。您可随时在系统设置或应用内关闭提醒。

三、第三方服务说明

3.1 WebDAV 备份（可选、用户自主配置）

本应用支持将您的学习数据备份到 WebDAV 服务器，该功能具有以下性质：

  • 完全可选：不配置即不使用，应用此时不产生任何网络行为；
  • 您自主选择服务商：服务器地址由您自行填写（如坚果云或您自建的服务），我们不提供、不中转、不接触该服务器；
  • 凭据仅存本机：您填写的 WebDAV 账号与应用密码仅保存在本机数据库，用于向您的服务器发起认证请求，不会发送给开发者或任何第三方；
  • 传输内容：仅上传/下载您的学习数据备份文件（JSON 格式），不含其他信息。

使用该功能前，请您自行阅读并同意您所选择 WebDAV 服务商的隐私政策与用户协议。

3.2 本地语音合成（TTS）

听写与朗读功能使用设备系统内置的离线语音引擎（华为设备为系统语音服务）。语音合成在本机完成，不将文本上传至网络。若设备未安装语音引擎，相关功能将给出友好提示并降级，不影响其他功能。

3.3 系统能力

应用使用的日历倒计时、通知栏、深浅色主题等均为系统本地能力，不涉及数据出设备。

四、未成年人保护

本应用不面向 14 周岁以下儿童运营，不收集任何用户信息，也不含社交、支付等未成年人不宜功能。若您为未成年人，建议在监护人陪同下阅读本政策后使用。

五、数据存储与安全

  • 存储位置：全部学习数据保存在设备本机的应用沙箱数据库中，随应用卸载一并删除；
  • 传输安全：WebDAV 备份经由您自行选择的服务器完成，建议您优先选择支持 HTTPS 的服务商；
  • 无云端存储：我们在任何服务器上均不保存您的任何数据，因此也无法为您找回未备份的数据，请善用本机快照与 WebDAV 备份功能。

六、您的权利

由于本应用不收集、不上传任何个人信息，您对数据拥有完整控制权：

  1. 查看与导出：您可在错词本中复制导出错词文本；
  2. 更正：所有学习设置可随时在应用内修改；
  3. 删除：卸载应用或清除应用数据即可彻底删除全部本机数据；WebDAV 云端备份由您自行在其服务商处管理删除；
  4. 撤回授权：您可随时在系统设置中关闭本应用的通知权限，或在应用内关闭考试提醒开关；
  5. 注销：本应用无账号体系，无需注销。

七、政策的变更

如应用功能变更导致数据处理方式发生变化（例如新增联网功能），我们将在应用内显著位置提示并更新本政策与生效日期。重大变更前，我们会在应用内提前公告。
